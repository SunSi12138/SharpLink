# SharpLink 0.8.37 deep audit

Chinese: [`../audit-0.8.37.md`](../audit-0.8.37.md)

Using exact 0.8.36 commit `e4bf5f1`, this batch proved five Generator P2 improvements and one additional P2 test-gate correction. Inaccessible service/explicit DTO declarations leaked raw generated C# accessibility errors; keyword DTO members produced invalid composed local names; unsealed record Codecs silently sliced derived state; ref-like payloads produced illegal generic/field artifacts; and static abstract operators or conversions left generated Proxies unable to implement their contracts. The 0.8.36 admission/drain probe also modeled production's atomic state transition with a weaker volatile store, permitting a false ARM64 store-buffering witness under process-level load.

The Generator now validates the complete containing-type accessibility chain while preserving same-assembly internal and protected-internal declarations. DTO models keep raw names for composed locals and escape only member access. Native record classes must be sealed. Ref-like roots report `SHARPLINK009` before the unmanaged shortcut and suppress their contract artifacts. Abstract operators/conversions report `SHARPLINK054` and suppress their Proxy/Stub.

The complete pre-fix Generator run contained 113 tests: all 108 existing tests passed and exactly five new probes failed. An executable exact-baseline record probe printed `RECORD_SLICE_PROVEN runtime=DerivedPayload decoded=BasePayload value=7`, proving actual state slicing. After fixes, Generator is 113/113. Assertion and pseudo-mutation review covers rejected and allowed accessibility, keyword local/member separation, the sealed record boundary, ref-like diagnosis plus artifact suppression, and operator diagnosis plus artifact suppression. The race probe now uses the same `Interlocked.Exchange(ref int, int)` boundary as production and passed three consecutive complete Unit reruns at 483/483.

No Runtime, Client, or Server hot path changed. Interleaved exact-0.8.36/current non-incremental HostApplication builds measured median wall time 2.13 -> 1.89 seconds, with no build regression. The non-incremental Release build has zero warnings/errors, Unit is 483/483, and Integration is 240/240. A 120-second shared-memory Chaos run completed 866,582 successes, 337,510 expected failures, zero unexpected failures, and 23 restarts with zero Client/Server Errors and a complete zero-metric drain.
