coverage too. Only the explicitly compiled diagnostic binary contains the
sampling/reflection code. It reports participant/pump states and standalone

TryEnter skips a busy state; it never queues a diagnostic command, consumes
credit, retries an admission, wakes a participant or extends the case deadline.
Snapshots are concurrent observations, not atomic conservation proofs.

four processes and stops on the first failure. All logs and exit codes are
